# WHLOL Cheat

Чит для CS2 с функциями ESP, Aimbot, Silent Aim, Triggerbot, RCS, Bhop, Auto-Stop.

**made by FREAK1337**

---

## ФУНКЦИИ

- **ESP** — боксы, HP, броня, имена, оружие, дистанция
- **Skeleton** — скелет игроков
- **Aimbot** — плавное наведение, FOV, кость
- **Silent Aim** — попадание без наведения
- **Triggerbot** — авто-выстрел
- **Auto-Stop** — сброс скорости при стрельбе
- **RCS** — контроль отдачи
- **Bhop** — авто-прыжок
- **Auto Strafe** — авто-стриф
- **Radar** — мини-карта
- **Bomb Timer** — таймер бомбы
- **Spectator List** — кто смотрит
- **Anti-Flash** — защита от вспышек
- **FOV Changer** — свой FOV
- **Steam Profile** — аватарка и ник
